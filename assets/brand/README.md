# 242Places brand assets

The approved mark is **2 – Republic of Congo silhouette – 2**. The country contour is retained; it is not cut into a numeral 4. Both numerals reference a single `two` SVG path, so their shapes and bottom bars are identical. The website combines the mark with a Chakra Petch wordmark aligned with the geometric numerals; body copy remains Inter.

`mark.svg` is the shared current-color artwork used inline by the native API documentation. The web assets in `apps/web/public/brand` provide light/dark/monochrome SVG, a transparent PNG for local social-card rendering, and app icons. The small favicon uses the country silhouette alone on charcoal to retain legibility. No raster image is used for the header logo.

The silhouette is adapted from [Simplemaps Republic of Congo SVG](https://simplemaps.com/svg/country/cg), © Pareto Software / Simplemaps, under its [free SVG library license](https://simplemaps.com/resources/svg-license). It is incorporated into this original logo, not redistributed as an unchanged map collection. It is branding artwork, not measured geographic coverage for the data catalog.

Français : le logo approuvé associe deux chiffres 2 strictement identiques à la silhouette de la République du Congo, sans transformation en 4. Les variantes clair/sombre utilisent le même tracé ; le favicon privilégie la silhouette pour rester lisible. Le mot « Places » et les titres du site utilisent Chakra Petch ; les textes courants conservent Inter. Le contour adapté de Simplemaps reste soumis à la licence ci-dessus, distinctement du code MIT.
